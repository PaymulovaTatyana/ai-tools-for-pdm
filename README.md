# Кто выгуливает Бориса

Учебное Node.js-приложение для вымышленной компании «Догяндекс». На общей странице сотрудники видят пять сегодняшних прогулок и могут занять свободный слот. Карточка кормления показывает последнюю отметку.

## Запуск

Нужен Node.js 24 или новее со встроенным модулем `node:sqlite`. Установка пакетов не нужна.

```sh
npm run check
npm start
```

Откройте [http://127.0.0.1:3011](http://127.0.0.1:3011/). Приложение создаёт `boris.sqlite` рядом с `server.js`. При перезапуске используется тот же файл. Дата и время кормления показаны по Москве.

## Главный сценарий

1. Откройте страницу в двух браузерах. Выберите одинаковый свободный слот в каждом.
2. В первом браузере введите «Анна Тестова» и подтвердите запись. Слот покажет «Занято» и имя.
3. Во втором браузере отправьте форму с «Илья Примеров». Сервер вернёт HTTP 409, покажет исходную запись и предложит другое время.
4. Обновите страницу и сверьте имя. Для дополнительной проверки отметьте кормление как «Ольга Учебная» и проверьте имя и время.

Если повторно запускаете сценарий в тот же день, выберите ещё свободный слот. Для проверки чистого состояния распакуйте архив в отдельную папку и запустите тот же код.

## Границы

Одна общая страница, один пёс и пять слотов на текущую дату. Состояние хранится в SQLite. В проекте используются синтетические имена. Авторизация, отмена записей, недельный календарь, уведомления и внешние интеграции вне учебного объёма.
